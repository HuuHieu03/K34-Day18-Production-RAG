## 3. 🛠️ Nhật Ký Lỗi & Cách Xử Lý (Troubleshooting)

### 🔴 Sự cố 1: `ModuleNotFoundError: No module named 'pypdf'` khi chạy lệnh `pytest`
- **Triệu chứng (Symptom / Error Message)**:
  ```text
  FAILED tests/test_m1.py::test_compare_all_strategies - ModuleNotFoundError: No module named 'pypdf'
  ```
- **Nguyên nhân gốc rễ (Root Cause)**:
  - Môi trường ảo `.venv` (Python 3.11) đã cài đầy đủ `pypdf 6.16.1`, tuy nhiên file `requirements.txt` ban đầu không chứa `pytest`.
  - Khi gõ trực tiếp `pytest` trên PowerShell, hệ điều hành tự động fallback về gọi `C:\Users\ADMIN\AppData\Local\Programs\Python\Python310\Scripts\pytest.exe` (Python 3.10 global - nơi không cài `pypdf`).
- **Giải pháp khắc phục (Fix / Solution)**:
  - Cài đặt `pytest` trực tiếp vào `.venv` bằng `uv`:
    ```bash
    uv pip install pytest
    ```
  - Chạy test thông qua `uv run pytest` hoặc thực thi trực tiếp bằng binary của `.venv`:
    ```bash
    .\.venv\Scripts\pytest.exe tests/test_m1.py -v
    ```
